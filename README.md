# Médecin Conscient — Accueil redesign

Base statique HTML/CSS/JS conforme au cahier des charges fourni.

## Fichiers
- `index.html` : structure de la page + objet `media` centralisé + interactions.
- `styles.css` : design éditorial blanc/noir/violet, responsive mobile-first.
- `media/` : emplacement réservé aux médias propres à Médecin Conscient.

## Médias Médecin Conscient
Remplacer simplement :
- `/media/medecin-01.jpg`
- `/media/medecin-02.jpg`
- `/media/medecin-03.jpg`
- `/media/video-01.mp4`
- `/media/video-02.mp4`

Les visuels génériques de démonstration sont regroupés dans l'objet `media` au début du script dans `index.html` afin de pouvoir les remplacer depuis un seul endroit.

## Vues
Aucun nombre de vues réel n'est inventé : la maquette affiche `[VUES]`.

## Lancer
Ouvrir `index.html` dans un navigateur ou servir le dossier avec un serveur statique.
